# Дорожная карта FoxTunnel

**Русский** · [English](ROADMAP.en.md) · [Содержание](../README.md) · [Актуальный исходный код](https://github.com/SawaMEN/FoxTunnel/tree/main)

Единственный актуальный план. Ранее дублировавший его `NEXT-STEPS` удалён. Дата пересмотра: **19 октября 2026 г.** Чекбокс отмечает **наличие реализации в `main`**, а не готовность к промышленной эксплуатации.

## Реализовано в исходниках

| Этап | Статус | Где смотреть |
|---|---|---|
| 1. База, воспроизводимые сборки и проверки | Реализовано; релизы выпускаются отдельно по запросу/тегу | [Дистрибуция](../reference/DISTRIBUTION.md), [совместимость](../reference/COMPATIBILITY.md) |
| 2. Mozilla TLS/H2 | NSS для TCP, профиль и измерения различий; **полного Firefox-паритета нет** | [Mozilla profile](../research/MOZILLA-CLIENT-PROFILE.md) |
| 3. Передача данных | Ограниченные bond-каналы, coalescing и локальные бенчмарки; прирост скорости в Интернете не доказан | [Bond](../architecture/BONDING.md), [результаты](../research/DATA-PATH.md) |
| 4. Mozilla Neqo/H3 | Экспериментальный Linux amd64 backend с CA/SNI/SPKI и ограниченным H2 fallback; стандартный H3 — quic-go | [Neqo](../research/NEQO-INTEGRATION.md) |
| 5. Управление доступом | Локальные пользователи, отзыв, ротация и квоты; нет распределённого управления | [Access](../reference/ACCESS.md) |

Код перечисленных этапов объединён в `main`. Проверка отдельных веток **не гарантирует** успешность каждого интеграционного CI-задания: смотрите статус текущего коммита GitHub Actions. Опытные функции Neqo и NSS не следует считать готовыми к production.

## Далее

1. **Полный VPN:** приложенческий UDP, TUN, маршруты, DNS/IPv6 и kill switch. Требуются тесты утечек при сбоях и смене сети.
2. **Эксплуатация:** автоматизированная установка, обновление/откат, реальные испытания ОС, длительные нагрузки, память NSS/Rust, внешняя проверка безопасности.
3. **Полевые измерения:** одинаковые условия для Firefox/NaiveProxy/FoxTunnel, packet capture, RTT/потери, работа разных операторов, воспроизводимые исходные данные.
4. **Интеграции:** дополнительные клиенты и панели только после стабилизации API и wire-контракта.

## Правила готовности

- **Наличие кода ≠ доступность релиза:** публикацию проверяйте в GitHub Releases.
- **NSS ≠ Firefox:** одинаковые криптобиблиотеки не воспроизводят браузерный HTTP/2, Necko или внешние отпечатки.
- **Neqo ≠ обход блокировок:** нет доказательств устойчивости к ТСПУ или превосходства над NaiveProxy.
- Каждый новый backend: отказ при несовместимости без тихого downgrade, CA/SNI/pin до секретов, интеграционный тест, запуск `go test -race`, ограничение памяти и описание особенностей платформ.
