## Подготовка

Нужны сервер с доменом, DNS-записью, открытым TCP-портом 443 и действительным
TLS-сертификатом для этого домена. Сертификаты и firewall настраиваются отдельно.

Скачайте полный архив из [Releases](https://github.com/SawaMEN/FoxTunnel/releases).
Для Linux NSS сохраните `lib/`, метаданные и лицензии рядом с программой.
Проверка архива описана в [эксплуатации](OPERATIONS.md).

Обычная сборка из исходников требует Go 1.26.10+ и не включает NSS/Neqo:

```sh
go build -o foxtunnel ./cmd/foxtunnel
./foxtunnel version --json
```

## Сервер

Замените домен и пути на свои. Каталог `server-config` ещё не должен существовать.

```sh
./foxtunnel setup \
  --server https://vpn.example.com \
  --cert /etc/ssl/foxtunnel/fullchain.pem \
  --key /etc/ssl/foxtunnel/privkey.pem \
  --out server-config

./foxtunnel server --config server-config/server.json
```

`setup` создаёт:

| Файл | Назначение |
|---|---|
| `server.json` | Приватная конфигурация сервера |
| `connection.txt` | Профиль подключения с паролем; передаётся клиенту |
| `node.json` | Описание ноды для добавления в кластер |
| `cluster.json` | Список нод hub |

Созданный профиль включает Bonding/discovery для hub; второй сервер для запуска не нужен.

Храните конфигурацию и ключи вне публичной папки сайта. Для постоянной работы
запускайте сервер через службу ОС или супервизор.

## Клиент

Безопасно скопируйте только `connection.txt` на клиент и ограничьте доступ
к файлу его владельцем.

```sh
./foxtunnel client --link-file connection.txt
```

Укажите в приложении SOCKS5 `127.0.0.1:1080` и DNS через прокси.
Проверка:

```sh
curl --socks5-hostname 127.0.0.1:1080 https://example.com/
```

Прокси обслуживает приложения, в которых он настроен. Для всего устройства
нужен VPN-клиент с собственным TUN и настройкой сети.

## Если не работает

| Ошибка | Что проверить |
|---|---|
| TLS | Домен, SNI, срок сертификата, полную цепочку и доверенный CA |
| Нет подключения | DNS, TCP 443, firewall и работу сервера |
| Отказ авторизации | Профиль подключения и актуальность пароля |
| Сайт не открывается | SOCKS5 в приложении, DNS через прокси и ограничения назначения |
| HTTP/3 недоступен | UDP-порт сервера и выбранный транспорт; сначала проверьте HTTP/2 |
| NSS/Neqo недоступен | Реальные возможности сборки в `version --json` |

Транспорт и параметры профиля задаются при `setup`. Допустимые дополнительные
флаги проверяйте через `client --help`: не все настройки можно совмещать
с `--link-file`. Для частного CA используйте `--ca-cert`, сохраняя проверку имени.
