# VetroffProxy v0.1.0

Название проекта — VetroffProxy, команда — `vetroff`.

Релиз публикует по одному полному архиву Linux AMD64 и ARM64:
`vetroff_0.1.0_linux_amd64.tar.gz` и `vetroff_0.1.0_linux_arm64.tar.gz`.
Каждый архив содержит CLI с NSS, полный Necko runtime, нативный helper и лицензии.
Сохраняйте весь каталог с `lib/` и `runtime/`.

TCP/UDP, SOCKS5, XHTTP, Bond и каскады используют существующие контракты.
Путь Go-модуля, переменные `FOXTUNNEL_*`, ссылки `vetroff://` и сетевые
идентификаторы сохранены для совместимости.

Перед публикацией обязательны нативные проверки обеих архитектур,
установка/обновление/откат, передача данных CLI/SDK, проверка архивов и provenance.
Отдельный gate собирает закреплённый старый исходный код и проверяет
совместимость старого и нового процессов в обе стороны. Удалённый исторический
архив alpha.1 не считается проверенным: его доступность отмечается отдельно.

Протокол и Mozilla runtime остаются экспериментальными. Этот релиз не подтверждает
неотличимость от Firefox или работоспособность при любом DPI.
