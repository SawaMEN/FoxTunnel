# VetroffProxy v0.1.0

Исправленная сборка из текущего main после очистки namespace.
Команда — `vetroff`, переменные окружения — `VETROFF_*`, Go-модуль —
`github.com/SawaMEN/VetroffProxy`. Клиент и сервер обновляйте одновременно:
старые сетевые идентификаторы больше не поддерживаются.

По одному полному архиву для Linux AMD64 и ARM64: CLI с NSS, нативный helper,
Mozilla Necko runtime и лицензии. Сохраняйте весь каталог с `lib/` и `runtime/`.
Точный коммит и контрольные суммы указаны выше в сгенерированном описании.

Сборка runtime и нативные проверки обеих архитектур выполняются перед публикацией.
Исправленный выпуск заменяет предыдущие архивы 0.1.0; загрузите их заново.
Протокол и Mozilla runtime остаются экспериментальными.
