# VetroffProxy v0.1.0-alpha.2 — experimental Mozilla Engine

**Experimental prerelease · Linux amd64 only · Not a production VPN.**

This release packages a versioned VetroffProxy CLI together with pinned NSS
3.130 and Rust Neqo 0.33.0, including all required Mozilla runtime
libraries. Opt-in `--engine mozilla` selects NSS/TLS and Neqo/HTTP3
where supported; controlled H3-to-H2 reachability fallback is available.

## Included changes

- Native Mozilla selection, pinned packaging and measured HTTP2 initial
  Firefox 158 SETTINGS order
- Neqo connection lifecycle and GOAWAY draining, bounded pool,
  coordinated pre-request reachability probes and network-change hook
- Local Go SDK and CLI diagnostics with no remote analytics
- TLS and transport fixes from the cross-component review: NSS TLS input
  validation, ALPN/version policy, client certificate rejection and x509
  verification time; Neqo final response delivery; POST nil headers,
  request-body cleanup and typed-nil transport errors
- Repeatable real-socket CI for H2 and H3; strict offline package,
  runtime license and SHA256 verification

## Files

- `vetroff_0.1.0-alpha.2_linux_amd64_mozilla.tar.gz`
- `SHA256SUMS`, external metadata, verified release and gate reports

Unpack the **entire** archive. Keep `lib/` next to `vetroff`.
Use `./vetroff version --json` to inspect the runtime. Follow
[distribution instructions](../DEVELOPMENT.md)
for provenance and checksum verification.

## Important limitations

- This is an experimental SOCKS5 tunnel with opt-in UDP relay and Linux TUN, not a production-grade system-wide VPN or
  complete Firefox/Chromium browser stack.
- Firefox fingerprint parity, NaiveProxy equivalence and successful
  censorship/allowlist bypass **have not been demonstrated**.
- CI network tests run on isolated loopback, not remote mobile networks.
- The legacy NSS-only GitHub Releases and original main-branch workflow
  are unaffected; this version is an opt-in Mozilla Linux amd64 prerelease.
