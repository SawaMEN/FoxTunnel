# FoxTunnel v0.1.0-alpha.1

[Каталог](../README.md) · [Релизы и проверка](../reference/DISTRIBUTION.md)

> **Исторический выпуск.** Страница относится только к v0.1.0-alpha.1.

Первый экспериментальный выпуск FoxTunnel. Протокол и SDK пока нестабильны.

> Исторические примечания к v0.1.0-alpha.1: перечисленные ниже платформы и файлы описывают именно этот опубликованный релиз. Новые выпуски собираются только для Linux amd64/arm64 (go и nss), без отдельных manifest.json и SHA256SUMS. См. [актуальную схему поставки](../reference/DISTRIBUTION.md).

- Самостоятельный TCP-клиент/SOCKS5 и сервер, TLS 1.3 с проверкой CA/имени и дополнительным SPKI pin.
- Семь транспортов: H2 CONNECT/POST, WSS, H3 POST и три режима XHTTP. Кластер/discovery и экспериментальный bond через общий выход.
- Публичный Go SDK, wire draft 0, русская/английская документация.
- Девять архивов: Go для Linux amd64/arm64/armv7, macOS amd64/arm64, Windows amd64/arm64; NSS для Linux amd64/arm64.
- NSS-архивы включают закреплённые библиотеки Mozilla. Сохраняйте каталог `lib/` рядом с бинарником; база Linux NSS — Ubuntu 24.04, требуются совместимые glibc/libgcc.
- `manifest.json`, `SHA256SUMS` и offline verifier проверяют состав/метаданные/содержимое комплекта. Контрольные суммы не являются цифровой подписью.

Перед запуском выберите точную версию/платформу/backend, проверьте архив и фактический `version --json`. Сохраните прежний каталог версии и конфигурацию для отката. Секреты доступа не публикуйте.

Ограничения: NSS + Go HTTP/2 не воспроизводят весь Firefox; H3 использует quic-go, не Neqo. UDP приложений/TUN/kill switch отсутствуют. macOS/Windows проверены кросс-сборкой, без нативной сертификации и подписей. Общий выход остаётся точкой отказа. Превосходство над NaiveProxy и устойчивость к ТСПУ не установлены.

English: experimental standalone FoxTunnel, not a production VPN release. Pin the exact version/commit/target, verify manifest/checksums and archive contents before use. Linux NSS bundles a pinned Mozilla runtime; keep `lib/` beside the executable. No full Firefox parity, application UDP/TUN, executable signing or proven censorship resistance. Retain the previous version/configuration for rollback.
