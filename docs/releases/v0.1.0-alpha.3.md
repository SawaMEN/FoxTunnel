# FoxTunnel v0.1.0-alpha.3

This release brings the full Mozilla Necko engine into the main CLI and Go SDK
on Linux amd64. The distribution owns the native process and verifies its files;
no manual helper startup is required. H2/H3 CONNECT, half-close, private IPC and
shutdown are tested against the packaged CLI and SDK. Linux amd64 and arm64 NSS
archives remain available separately.

Fixed a Neqo response truncation race: a peer's STOP_SENDING now ends only the
upload direction, while a valid response can finish. RESET_STREAM still fails
the response. Tests cover blocked and backpressured uploads, trust changes and
TLS resumption. Bundle integrity tests run independently of the host execution
platform, restoring ARM64 release validation.

Publication requires Go race/vet and dependency checks, native NSS validation on
both architectures, Neqo Rust/interop/lifecycle checks, and the complete Necko
runtime gates including five-minute H2/H3 resource measurements. Archives are
signed with GitHub artifact attestations and checked again before publication.

Experimental prerelease. Full Necko currently supports Linux amd64 TCP CONNECT;
controlled comparisons do not establish stock Firefox identity, DPI
indistinguishability, or arbitrary-network reliability.
