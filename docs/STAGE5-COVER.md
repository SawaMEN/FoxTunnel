# Stage 5/8 — HTTPS cover и безопасность публичного сайта

**Статус:** подэтап 1 из 5. Ветка `up`. Этап 4 остаётся
открытым (1/5). Завершение этого подэтапа не означает завершение
HTTPS-маскировки или устойчивость к DPI.

## Что уже было до этапа 5

- Сервер использует один HTTPS listener для аутентифицированного
  H2/H3/WSS туннеля и обычных HTTP-запросов.
- Приватный трафик поступает на tunneling handler **только после**
  корректного Proxy-Authorization или managed access.
- `Server.cover` не передаёт в публичный обработчик
  `Proxy-Authorization` и заголовки `X-FoxTunnel-*`.
- Локальный `NewCover` не перечисляет каталоги, не обслуживает dotfiles,
  разрешает только GET и HEAD; проверки `CheckPublicRoot` предотвращают
  публикацию явно указанных приватных конфигураций.

## Подэтап 1: запрет symlink alias, целостность ответов

Ранее `os.OpenRoot` защищал от выхода **за пределы** каталога, но
следовал символическим ссылкам **внутри** каталога. Например, файл
`public.txt -> .secret` можно было запросить по обычному имени, не
совпадающему с запрещённым `.secret`.

Теперь `internal/tunnel/cover.go`:

1. Проверяет исходные компоненты URL до `path.Clean`, а также
   все компоненты пути под `os.Root`.
2. Запрещает symlink-компоненты, в том числе вложенные ссылки на
   внутренние dotfiles и конфигурационные файлы.
3. Открывает файл после `Lstat`, сверяет идентичность inode/объекта
   с `os.SameFile` и отдаёт **тот же уже открытый** файловый дескриптор
   через `http.ServeContent`, без повторного открытия в `FileServer`.
4. Сохраняет HEAD, Range/206, content type, обычный index.html
   и HTTP-редиректы `/directory -> /directory/`,
   `/index.html -> ./`.

Это именно защита от случайного размещения ссылок на приватные файлы;
**публичным каталогом должен владеть оператор**. Не давайте недоверенным
пользователям право одновременно записывать/переименовывать содержимое,
не храните в нём секреты и не рассчитывайте на неизменность файлов при
злонамеренном параллельном изменении дерева. Твёрдые ссылки на секреты
внутри публикации тоже недопустимы.

## Проверка

~~~sh
go test -race ./internal/tunnel -run '^(TestStage5|TestCover|TestStage2Cover)' -count=4
go test ./internal/tunnel -run '^TestStage5' -count=20
~~~

Набор `stage5_cover_test.go` проверяет symlink alias, скрытые файлы,
вложенные ссылки, отсутствие листинга и эхо-проб, GET/HEAD, Range,
права доступа и изоляцию приватных заголовков при ошибочной авторизации.
