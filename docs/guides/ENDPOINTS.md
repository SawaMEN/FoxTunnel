# Доверенные серверы и распределение потоков

**Русский** | [English](ENDPOINTS.en.md)

Можно задать до восьми собственных или явно доверенных HTTPS-прокси:

```sh
./foxtunnel client \
  --server https://edge-a.example \
  --fallback-server https://edge-b.example \
  --fallback-server https://edge-c.example \
  --balance least-active \
  --connect-timeout 15s \
  --fallback-attempt-timeout 5s
```

Все получают одинаковые учётные данные только после проверки TLS 1.3 и h2 ALPN.
На каждом сервере настройте сертификат и авторизацию. Не добавляйте случайные
публичные прокси. В URL запрещены учётные данные, путь кроме `/`, запрос,
фрагмент, повторяющийся адрес и открытый HTTP. `--ca-cert`, реализация TLS и
дополнение записей одинаковы для всех. В обычном CONNECT автопоиска нет.
Для bond есть отдельный явный [режим главной ноды](../architecture/CLUSTER.md); редиректов нет.

## Выбор и восстановление

| Режим | Поведение для нового потока |
| --- | --- |
| `failover` — по умолчанию | Последний рабочий сервер, другой — при временной сетевой ошибке установки |
| `round-robin` | Начальный сервер меняется по кругу; подходит для похожих по мощности узлов |
| `least-active` | Минимум устанавливаемых и открытых потоков этого клиента; равные варианты чередуются |

Счётчик резервируется атомарно вместе с выбором и освобождается один раз при
закрытии. Он не отражает общую загрузку CPU, полосу сервера и других клиентов.
H2 уже мультиплексирует потоки. Ввод-вывод выполняют горутины, а среда Go
распределяет вычислительную работу между доступными ядрами. Отдельного пула
системных потоков и чередования пакетов одного потока между серверами нет.

На установке каждый сервер пробуется не более раза. Общий бюджет по умолчанию
15 секунд, на один сервер при нескольких адресах — до 5 секунд. До успешного
CONNECT и подтверждения дополнения данные приложения не отправляются. После
успеха таймер установки отключён: здоровая SSH-сессия или загрузка не завершается
по этому таймеру.

После временного сетевого сбоя сервер уступает место доступным на 1, 2, 4, 8,
16 и максимум 30 секунд. Если все оставшиеся адреса в паузе, попытка начинается
сразу: пауза не блокирует восстановление. Фоновых проб и циклов переподключения
нет. Успех сбрасывает паузу; повторная оценка происходит при новом запросе.
Это ограниченное восстановление, а не оптимизатор задержки или полосы.

Ошибки сертификата, TLS, ALPN, HTTP-статуса и согласования дополнения завершают
текущую установку. В частности, 401/403/503 не повторяются молча на другом узле.
Отмена родительского контекста останавливает все попытки. Проверка подлинности
не ослабляется, перехода на открытый протокол нет.

Установленный поток остаётся на своём сервере. При его отказе поток закрывается;
данные не воспроизводятся и не переносятся. Потоки на других узлах могут
продолжить работу. Один большой файл не скачивается сразу через несколько
серверов. Разные узлы могут давать разные выходные IP. Потоки одного H2/TCP
соединения по-прежнему разделяют восстановление после потерь TCP.

## Ограничения и проверки

Большее число соединений меняет наблюдаемую картину трафика. Распределение и
смена адресов не доказывают защиту от классификации и блокировок IP. При
блокировке всех настроенных узлов эти режимы не восстанавливают связь.
HTTP/3, DNSTT, раздельный HTTP-транспорт и совместимость с Sudoku не добавлены.

Тесты настоящих H2-соединений с Go TLS и NSS проверяют распределение, выбор
освободившегося узла, закрытие, недоступные/зависшие серверы, общий бюджет времени,
конечность ошибок сертификатов/HTTP/дополнения, отказ HTTP/1 до авторизации и
отсутствие повтора установленного потока. Параллельные резервирования и
восстановление после паузы проверяются детектором гонок. Реальная скорость
маршрутов и поведение ТСПУ в РФ требуют отдельных измерений.

## Эксперимент объединения путей

Отдельный явный режим `--bond` передаёт блоки одного потока через несколько
входов к общему выходу. Обычные режимы распределения целых потоков сохранены.
См. [запуск, подтверждения, границы и проверки](../architecture/BONDING.md).
Это прототип: преимущество скорости и устойчивость к ТСПУ не доказаны.
